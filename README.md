# Mushroom Classification Using PySpark

## Overview

This project is the final project for the **Big Data Processing** course. It focuses on processing, analyzing, and classifying mushroom data using **Apache Spark and PySpark**.

The project applies data preprocessing, feature transformation, machine learning, model evaluation, and data visualization to classify mushrooms based on their physical characteristics.

The classification model used in this project is a **Gradient-Boosted Tree (GBT) Classifier** implemented using PySpark ML.

## Objectives

The main objectives of this project are:

- Process mushroom data using PySpark.
- Perform data cleaning and preprocessing.
- Transform multiple features into a machine learning feature vector.
- Split the dataset into training and testing sets.
- Build a mushroom classification model using Gradient-Boosted Trees.
- Evaluate the model using classification accuracy.
- Visualize relationships and distributions within the dataset.
- Analyze characteristics of mushrooms classified as edible.

## Dataset
- Source: Kaggle
- Size: 50,000+ rows
- Label: Edible / Non-edible (binary classification)

## Methodology
- Compared multiple classification algorithms
- Selected GradientBoostTree as final model based on performance benchmarking
